# Sistema Bancario

Proyecto en Java que simula un sistema bancario con cuentas de ahorro, corriente e inversión.  
Cada cuenta tiene su propia clase y parámetros asociados para calcular comisiones, retiros y saldos finales.  

# Organización
Todas las clases están en el paquete `banco`:
- `CuentaBancaria` (clase base)
- `CuentaAhorros` + `ParametrosAhorros`
- `CuentaCorriente` + `ParametrosCorriente`
- `CuentaInversion` + `ParametrosInversion`
- `Main` (ejecución del programa)

# Ejecución
Compilar y ejecutar `Main.java` para ver la salida en consola.
